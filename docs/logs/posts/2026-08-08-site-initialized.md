# 为什么建立这份 Python 学习记录

学习 Python 的过程中，我逐渐发现：真正容易丢失的并不是语法本身，而是当时为什么这样理解、如何验证，以及这些知识后来在哪个项目里发挥了作用。

<!-- more -->

## 想解决的问题

- 零散笔记缺少联系，过一段时间很难重新找到上下文。
- 项目通常只留下最终代码，技术选择和失败尝试没有被保存。
- 学习内容与实际项目相互分离，很难判断自己是否真正掌握。
- 对一个概念的理解会不断变化，需要保留修正过程。

## 我准备怎样记录

这份记录同时保留主题和时间两个方向：

- **专题**保存已经理解、验证并能够复用的知识。
- **项目档案**保存目标、实现、决策、问题和复盘。
- **日志**保存当时的疑问、过程和认识变化。

我希望它最终呈现的不是一条完美的学习路线，而是一份能够回看、修正和继续生长的经验记录。

## 现在的起点

- 继续整理 Python 语言核心和标准库的理解。
- 为使用 Python 创建的项目保留完整档案。
- 记录 AI 学习和实验中真正遇到的问题。
- 定期回看旧结论，把已经改变的认识明确写出来。
