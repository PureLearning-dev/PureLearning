# Python 工程化

工程区关注的是“如何让一段 Python 代码长期可靠地工作”。

## 建议专题

=== "质量"

    - 格式化与静态检查
    - 类型检查
    - 单元测试与集成测试
    - 代码审查清单

=== "交付"

    - `pyproject.toml` 与依赖管理
    - 包结构与版本号
    - 命令行应用
    - CI/CD 与发布流程

=== "运行"

    - 结构化日志
    - 配置与密钥
    - 性能分析
    - 错误监控与故障复盘

## 实践记录格式

每项实践建议记录四件事：

1. **约束**：项目面临什么问题。
2. **决策**：选择了什么方案。
3. **证据**：测试、指标或案例是什么。
4. **回看日期**：什么时候应该重新评估。
