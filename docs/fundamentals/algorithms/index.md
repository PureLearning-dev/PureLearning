# 数据结构与算法

这个目录用于整理语言无关的算法知识。Python 可以作为实现和验证工具，但笔记应先解释问题特征、推导过程和复杂度，再给出代码。

## 可以在这里记录

- 时间复杂度、空间复杂度和摊还分析；
- 数组、链表、栈、队列、哈希表、树、堆和图；
- 排序、搜索、递归、回溯、贪心和动态规划；
- 双指针、滑动窗口、前缀和等解题模式；
- 典型题目的错误思路、验证过程和可迁移结论。

## 推荐的文章结构

1. 问题具有哪些特征？
2. 为什么选择这种数据结构或算法？
3. 正确性如何解释或证明？
4. 时间和空间代价是多少？
5. Python 实现有哪些语言层面的注意事项？
6. 哪些边界条件通过测试得到了验证？
