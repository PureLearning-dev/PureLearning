## 示例：用问题驱动笔记

### `==` 和 `is` 的区别是什么？

`==` 比较值是否相等；`is` 比较两个名字是否指向同一个对象。

```python title="identity.py" linenums="1"
first = [1, 2, 3]
second = [1, 2, 3]
alias = first

assert first == second
assert first is not second
assert first is alias
```

!!! warning "常见误区"

    不要用 `is` 比较字符串或数字的值。实现可能复用某些对象，但那不是可以依赖的业务规则。
