# 学习路线图

路线图描述接下来要建立哪些能力；具体日期进展写入日志。

## 第一阶段 · 语言基础

- [ ] 数据类型、表达式与控制流
- [ ] 函数、作用域与模块
- [ ] 类与 Python 数据模型
- [ ] 异常和上下文管理器

## 第二阶段 · 编写可靠程序

- [ ] 文件、数据与常用标准库
- [ ] 类型标注与接口设计
- [ ] 自动化测试
- [ ] 日志、配置与错误处理

## 第三阶段 · 构建真实项目

- [ ] 命令行工具
- [ ] Web API 或数据服务
- [ ] 自动化任务或数据处理管道
- [ ] 打包、持续集成和发布

## 每月复盘

每月从日志中回答：

1. 本月真正掌握了什么？证据是什么？
2. 哪个问题反复出现，值得写成专题？
3. 哪个项目决策需要重新评估？
4. 下个月只推进哪三个重点？
