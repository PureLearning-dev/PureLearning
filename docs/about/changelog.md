# 网站更新历史

这里仅记录网站本身的结构、设计和功能变化。Python 学习、项目进展和 AI 实验请查看[日志](../logs/index.md)。

## 2026-08-09

### 标签与日志管理

- 启用 Material for MkDocs 标签插件，让专题、项目和日志可以通过共同标签互相关联。
- 在“关于本站”中增加标签索引，集中展示各标签及其对应页面。
- 将博客从日志中独立出来，并在顶部导航增加“博客”栏目。
- 日志保存学习与实践现场，博客负责发布经过整理、可以独立阅读的文章。
- 补充博客发布、分类与标签的使用说明。
- 将博客列表调整为克制的文章索引，并补充内容组织与建站实践文章。
- 为博客文章增加上一篇、下一篇快速切换入口。
- 将标签导航从“关于本站”迁移到博客侧边栏。
- 将“日志”从顶部一级导航收进博客栏目，保留原有日志地址。

## 2026-08-08

### 内容边界与导航调整

- 增加“关于本站”导航，集中放置本站介绍、作者、更新历史和技术说明。
- 引入 Awesome Nav，将集中式导航迁移为各目录独立维护的 `.nav.yml`。
- 将日志明确为 Python 学习、项目进展、AI 实验和思考复盘的时间记录。
- 将网站主题、导航和功能更新从学习日志中分离。
- 将顶部“深度学习”扩展为覆盖范围更广的“AI”。

### 首页与视觉

- 首页重新突出 Python、项目实践和 AI 内容。
- 首页首屏调整为简洁的文字排版，移除大面积装饰背景和分隔线。
- 全站使用 `Maple Mono NF CN` 字体。
- 保留 Material for MkDocs 默认背景、靛蓝导航以及深浅色主题。

### 初始版本

- 使用 Material for MkDocs 初始化静态网站。
