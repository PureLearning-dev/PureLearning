# 关于这个网站

这是一个围绕 Python、使用 Python 创建的项目以及 AI 探索持续更新的个人知识站点。

它保存的不只是整理后的结论，也包括学习过程中出现的问题、项目中的技术选择、实验结果、失败经验和阶段性的思考。内容会随着理解和实践不断修正，而不是在发布后保持不变。

## 主要内容

- **Python**：语言核心、标准库以及使用中的理解和经验。
- **项目实践**：项目目标、设计、实现、更新、问题排查与复盘。
- **工程实践**：测试、类型、依赖、工具、部署和代码维护。
- **AI**：机器学习、神经网络、PyTorch、生成式 AI 和应用实验。
- **日志**：学习现场、项目进展、实验过程与认识变化。
- **博客**：从日志和实践中进一步整理出的完整文章与经验总结。

## 内容之间的关系

日志先保存现场，项目档案保留完整上下文，适合独立阅读的内容可以整理成博客文章，经过验证的结论再沉淀进长期专题。不同页面之间会互相链接，让一段知识可以追溯到它来自哪个问题和项目。
